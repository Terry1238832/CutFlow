# CutFlow

中文 macOS 菜单栏文件剪切工具。独立实现 Command X 的核心工作方式：在 Finder 中按 `⌘X` 调用原生“复制”菜单命令，仅在此次剪切产生的文件剪贴板仍有效时，按 `⌘V` 调用原生“将项目移到这里”。文件移动、同名冲突和撤销由 Finder 处理。ForkLift 继续使用按键转换。当前 1.1.4 是本机验证中的候选版。

## 安装与使用

1. 解压 `CutFlow-macOS.zip`，将 `CutFlow.app` 拖入“应用程序”文件夹。
2. 双击打开。点击菜单栏的剪刀图标可打开设置。
3. 点击“打开辅助功能设置”，在“系统设置 → 隐私与安全性 → 辅助功能”中开启 CutFlow。macOS 27 中对应页面名称为“设备控制和数据访问”。若未列出，点击 `+` 添加安装后的应用。
4. 返回 CutFlow，点击“重新检测”。应用会显示检测结果，并实际尝试辅助功能调用和事件监听。
5. 在 Finder 选中文件或文件夹，按 `⌘X`；单击选中一个目标文件夹后按 `⌘V`，CutFlow 会通过该文件夹的原生快捷菜单移动进去，保持当前目录、视图和文件夹选择，不再自动进入目标。也可先进入目标目录后再粘贴。

只有此次有效剪切之后的 `⌘V` 使用上述目标规则；普通复制粘贴保持 Finder 原有行为。未选中单个普通文件夹时仍使用当前目录；不会把应用包当作目标文件夹。准备快捷菜单期间切换窗口、按 Esc、继续键盘/鼠标操作或更换剪贴板会取消移动。无法确认目标或菜单时停止并显示原因，不退回到打开文件夹的方式。文件夹快捷菜单优先使用辅助功能动作；不支持该动作时使用 macOS 15 起的 Control-Return，因此较旧系统可能需要先打开目标目录再粘贴。

这是本地构建、临时签名（ad-hoc）的应用，未使用 Developer ID 签名或提交 Apple 公证。如果系统阻止打开，可在核对源码后通过“系统设置 → 隐私与安全性 → 仍要打开”批准该应用。无需关闭 Gatekeeper 或 SIP。

### 开关已开启，但应用仍提示没有权限

系统中的开关可能对应旧签名或另一份同名应用。重编译后的临时签名会变化，旧记录可能无法授权当前进程。

1. 在应用中展开“授权诊断与应用位置”，检查实际调用结果及当前应用路径。
2. 在系统辅助功能设置中关闭、重新开启 CutFlow；如果系统要求触控 ID / 密码，请由本人验证。
3. 若仍失败，在列表中选中 CutFlow 并点击 `−` 移除，再点击 `+` 添加“定位当前应用”显示的准确路径，并开启权限。
4. 返回应用点击“重新检测”。必要时退出应用后重新打开。不要同时保留多个运行中的 CutFlow 副本。

若 CutFlow 已选中，但 `−` 仍为灰色，先退出 CutFlow 和“系统设置”，再重新打开“系统设置”并选择 CutFlow，检查能否移除旧记录。请确认选中的确是 CutFlow；完成系统要求的身份验证后，再添加当前应用。

1.0.1 的检测不会绕过系统权限：只有系统允许实际调用 / 监听，或可用的权限状态报告，才会判定可用；具体操作仍由 macOS 强制检查。

若权限正常但快捷键仍无效，展开“授权诊断与应用位置”，查看最近的快捷键处理结果。1.1.4 会区分未收到按键、文字编辑保护、复制超时及文件剪贴板捕获成功；也可点击“重启快捷键监听”。诊断仅保存在内存中，不记录输入文本或剪贴板内容。

## 已实现的行为

| 操作 | 结果 |
| --- | --- |
| Finder 中 `⌘X` | 复制所选文件，标记待移动；原文件暂留原处 |
| 同一文件管理器中 `⌘V` | 有有效剪切标记时调用原生移动，否则普通粘贴 |
| `⌘C` / 其他应用中的 `⌘X` | 取消旧剪切标记，保留原快捷键行为 |
| 剪贴板被其他内容替换 | 自动取消剪切标记 |
| `Esc` / 菜单中“取消当前剪切” | 取消剪切标记，剪贴板内容仍保留 |
| 手动 `⌥⌘V` | 交由文件管理器处理，并清除剪切标记 |
| 暂停 / 退出 | 清除剪切标记 |
| 剪切后不粘贴 | 不移动、不删除文件 |

- 支持 Finder，以及 ForkLift 官方版、旧版常见标识和 Setapp 版的本地文件快捷键。ForkLift 必须使用默认复制 / 移动快捷键。
- 中文设置界面、菜单栏常驻、开机登录启动、暂停开关。
- 默认开启文字编辑保护：检测到重命名、搜索或可编辑输入控件时保留原快捷键。辅助功能无法读取焦点时也不转换快捷键；若某个文件视图因此无效，可关闭此保护使用兼容模式。兼容模式下 Finder 的文件名 / 搜索框文字剪切可能失效。
- 为匹配淡化位置，在待剪切期间将文件 URL 暂存在内存中，取消或粘贴后清除；不把路径写入磁盘，不记录输入内容，不发出网络请求。

## 剪切后淡化（实验功能）

在设置中开启或关闭“剪切后淡化（实验）”。1.1.3 起新安装默认关闭，保留既有用户保存的设置。选中文件后按 `⌘X`，应用会尝试在可识别的项目上叠加半透明的浅色 / 深色遮罩，使项目视觉上变淡。需要两次位置核验，通常不会在按键的同一瞬间显示。

这是可关闭的视觉模拟，Finder 的图标本身没有被设置透明度。公开接口不提供这种能力；[Command X 官方 FAQ](https://sindresorhus.com/command-x)也明确说明无法修改 Finder 文件图标的透明度。

- 只在当前 Finder 窗口和文件身份可以验证时显示；显示前还会核对覆盖层实际位于来源窗口上方。不可识别或层序不符合要求时保留正常外观，并在设置中显示原因。
- 滚动、拖动、窗口或视图变化时会暂时隐藏并重新核对位置，可能出现短暂延迟。
- 点击其他应用时隐藏，取消、粘贴、剪贴板改变或退出时清除；覆盖层不接收鼠标和键盘输入。
- 不修改文件内容、自定义图标、扩展属性或隐藏标记；不需要屏幕录制权限。
- build 12 增加列表文件行、分栏文件项和画廊缩略图识别，仍待本机视觉验收；build 11 的图标视图已由用户确认有效。桌面和 ForkLift 不显示淡化；画廊的大型预览区不覆盖。Finder 的自定义背景和选中色可能无法得到与 Windows 一致的效果。
- 多个不同来源目录的文件、隐藏扩展名导致无法精确匹配的项目、Finder 未提供目录地址或大量项目导致读取超时的情况，会暂不显示淡化；剪切功能照常工作。
- 切到 CutFlow 设置后仍可查看上次淡化诊断，便于检查未显示的原因。
- Finder 不提供窗口目录地址时，使用路径栏中的真实文件 URL 核验来源；若提示无法确认位置，可在 Finder 的“显示”菜单开启“显示路径栏”。不会根据本地化的路径文字猜测文件位置。
- “选择文件测试淡化…”可以对指定测试文件运行 12 秒预览，结束后保留检测结果；预览不改动剪贴板或移动文件。测试模式允许返回设置查看结果，正常剪切仍只在 Finder 前台显示。

## 使用边界

- 不修改 Finder 原生透明度，也不增加右键“剪切”菜单；另提供上述实验覆盖淡化。
- 不支持 Finder 与 ForkLift 之间跨应用传递剪切标记。到另一个应用粘贴会遵循它的普通粘贴行为。
- ForkLift 远程 FTP/SFTP 项目不保证提供标准本地文件 URL，因此不列入本版支持范围。
- “取消剪切”只取消移动意图；再按 `⌘V` 仍可进行普通复制。
- 剪切标记在调用一次原生移动后消耗，即使随后取消冲突对话框；要重新移动，请重新剪切。
- 复制尚未完成时立即按 `⌘V`，该次按键会被忽略，避免粘贴旧内容；待状态显示“已剪切”后再按一次。
- 复制超过 1.5 秒未产生文件剪贴板则取消待剪切状态。
- 请勿与 Command X 或其他相同快捷键改写工具同时启用。
- 修改源码重新签名后，macOS 可能要求移除旧的辅助功能授权记录，再添加新版应用。

## 构建

要求安装 Xcode 或包含 Swift 编译器、macOS SDK 的 Command Line Tools。使用 Swift Package Manager，没有第三方依赖；可用 Xcode 打开 `Package.swift`。

```sh
bash scripts/build.sh
```

在 `dist` 中生成 Apple Silicon / Intel 通用 `CutFlow.app` 和 ZIP，部署目标 macOS 13 或更新。可指定输出目录：

```sh
bash scripts/build.sh /path/to/output
```

环境变量 `CUTFLOW_BUILD_CACHE` 可指定构建缓存路径；`CUTFLOW_SIGN_IDENTITY` 可指定本机钥匙串中的签名身份，默认 `-` 为临时签名。构建脚本不包含公证发布流程。脚本中的 `--disable-sandbox` 仅用于 SwiftPM 编译子进程，不会关闭系统安全机制。

运行测试：

```sh
swift test
```

## 源码结构

- `Sources/CutFlowCore/CutSession.swift`：独立剪切状态机和应用 / 文字控件规则。
- `Sources/CutFlow/KeyboardService.swift`：CGEvent 事件转换、剪贴板观察、辅助功能焦点检查。
- `Sources/CutFlow/AppModel.swift`：权限、偏好设置、登录项、界面状态。
- `Sources/CutFlow/FinderDimOverlay.swift`：实验淡化层、文件身份核验、异步位置跟踪与显示清理。
- `Sources/CutFlow/CutFlowApp.swift`：SwiftUI 设置和 AppKit 菜单栏入口。
- `scripts/build.sh`、`scripts/icon.swift`：通用应用打包、图标生成、本地签名。
